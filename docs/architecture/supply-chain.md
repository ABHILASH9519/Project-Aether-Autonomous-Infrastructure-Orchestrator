# Supply-chain evidence

The dedicated read-only CI workflow resolves Go dependencies, runs go mod verify, records the module inventory and builds the event-fabric image with its source revision label. Trivy v0.76.2 scans an exported Docker archive without access to the Docker socket and creates a CycloneDX SBOM and HIGH/CRITICAL vulnerability report. Artifacts are retained for 14 days.

This is reporting, not a security gate: findings do not yet fail a release; scanner errors or malformed reports do fail CI. Go module files generated and verified by CI run 46065864664 are committed. Builds use readonly module resolution, and CI runs go mod tidy -diff and go mod verify; lockfile changes must be intentional. The scanner only inventories the event-fabric image, not all infrastructure images. Tool and base image tags are versioned but not all digest pinned. The scan database is downloaded at runtime. No external registry publication, signature, attestation or production compliance claim is made. The first [scan run](https://github.com/ABHILASH9519/Project-Aether-Autonomous-Infrastructure-Orchestrator/actions/runs/46065864664) successfully generated the SBOM and vulnerability report with 8 CRITICAL and 181 HIGH findings (scanner result entries, not necessarily distinct CVEs). These are unresolved findings; the image is not cleared for production. Readonly dependency resolution passed in CI.

## Remediation work

Build and test toolchains are updated from Go 1.23 to the supported Go 1.26.11 security release (2026-11-10); see https://go.dev/doc/devel/release. The Go language version in go.mod remains unchanged. A new triage.json deduplicates findings across binaries by package type, installed version and CVE, and package-summary.json groups them with known fixed versions. Raw scanner findings are retained. [Follow-up scan 46067342671](https://github.com/ABHILASH9519/Project-Aether-Autonomous-Infrastructure-Orchestrator/actions/runs/46067342671) completed with 5 CRITICAL and 75 HIGH result entries, down from 8 and 181. These are counts across scanned binaries, not unique CVEs. The deduplicated report identifies five affected packages: klauspost/compress, OpenTelemetry SDK, x/net, x/text and gRPC. Third-party upgrades and rescanning remain necessary. No release security gate is enabled.
